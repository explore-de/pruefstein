How to Use MCP

Ask an AI assistant about your reports and checks instead of clicking through them.

Prüfstein speaks the Model Context Protocol, so an assistant such as Claude Code can read your reports, explain why a check failed and look up what a check asks your Mac. It signs in as you and can do exactly what you can do on these pages — no more.

1

Add Prüfstein to Claude Code

{#command mcp.claudeCodeCommand /}

Run this in Terminal. It adds the server for every project on this Mac.

2

Sign in, once

In Claude Code, type /mcp, pick pruefstein and choose Authenticate. Your browser opens the same sign-in page you use for this site. Once you have signed in, Claude Code keeps the login and renews it on its own.

OTHER MCP CLIENTS

Any client that supports Streamable HTTP and MCP's OAuth sign-in works. Point it at

{#command mcp.mcpUrl /}

It finds the sign-in page on its own. What it cannot find is which app to sign in as, so give it this client ID, with no client secret:

{#command mcp.clientId /}

and have it wait for the sign-in to come back on {mcp.redirectUri}, the only address the sign-in page will send you back to.

WHAT YOU CAN ASK

Area Everyone Admins also
Reports List your reports and read one in full, with an explanation of every failed check Everyone's reports
Checks List groups and checks, and what each one asks your Mac Add groups and checks
Users — List users, add one (sends the setup invite), ask one for a fresh report

For example:

  • “Why did my last Prüfstein report fail, and how do I fix it?”
  • “Which checks in the Access Control group look at the screen lock?”
    • {#if inject:currentUser.admin}
  • “Who has not reported in the last week? Ask them for a new report.”
  • “Add a check that FileVault is on.”
    • {/if}

SAME RULES AS THESE PAGES

The assistant works as you. It sees the reports you can see here and changes only what your role allows. Anything it adds, such as a check or a user, takes effect right away, just as if you had done it on these pages. Read what it plans to do before you let it.
