How to Report

The same three commands the invitation mail asks for — here for when that mail is buried.

We check company Macs against our ISO 27001 controls — disk encryption, screen lock, that sort of thing. The agent runs on your machine, on your say-so: it shows you every result and asks before it reports anything. Nothing runs in the background, and nothing is sent without you seeing it first.

BEFORE YOU START: OPEN TERMINAL

Every command below is typed into Terminal, an app that comes with every Mac. To open it, press ⌘ Command + Space, type Terminal and press Return. It is also in Finder under Applications → Utilities.

Copy a command from this page, paste it into the Terminal window with ⌘ Command + V and press Return. Wait until it has finished before you paste the next one. If it asks for a password, type the one you log in to your Mac with — nothing appears while you type, and that is normal.

BEFORE YOU START: HOMEBREW

The agent is installed with Homebrew, which does not come with a Mac. To see whether you already have it, run: 

brew --version

If that prints a version number, go on to step 1. If it says command not found, install Homebrew first: 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

It asks for your password and takes a few minutes. When it finishes it prints Next steps with a few more commands — run those too, then close Terminal and open it again, or brew will still not be found.

ONE PREREQUISITE

The checks are run through osquery, so osqueryi has to be on your PATH. The install command above brings it along. If it is missing anyway, pruefstein-agent run stops and tells you how to install it.

WHAT HAPPENS AFTER YOU REPORT

A run that passes everything closes as compliant on the spot. A run with failures stays open for a repair window: fix what it found, report again before the deadline, and the same report closes compliant instead. Let the window run out and it is recorded as non-compliant. Your reports are under Reports, each one listing what passed, what failed and why.
